There is no picture-in-picture button, in the chrome or on this page: PiP is the developer's decision. This player is created with autoEnterPip: true, so the browser may take the video into PiP on its own where it offers that — Safari when you switch tabs or apps, Chrome on a tab switch for sites it allows auto picture-in-picture (the media-session enterpictureinpicture action the SDK registers). The browser's own PiP controls work too, and your code enters it with await player.enterPip() from a click or key handler of your own UI (browsers grant PiP to a user gesture); player.exitPip() leaves it. During an ad break PiP is not offered. Every transition fires og-pipchanged (detail.isActive) and the PictureInPictureChanged analytics event — both stream below, with the tab's visibility changes.
